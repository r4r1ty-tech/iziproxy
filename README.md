# IziProxy

Кроссплатформенный инструмент на C# для автоматического развёртывания и управления прокси-серверами **Xray (VLESS + XHTTP + REALITY)** на чистых VDS/VPS (Ubuntu/Debian).

Графический интерфейс построен на **Avalonia UI** (версии 12) и запускается на Windows, Linux и Android из единой кодовой базы.

---

## Что умеет

1. **Подключается к VPS по SSH/SFTP** и загружает встроенные скрипты развёртывания.
2. **Запускает bash-скрипт** (`Deploy.sh`), который устанавливает Xray, включает TCP BBR, подбирает домены для маскировки прямо с сервера, настраивает брандмауэр, генерирует пару ключей x25519 и UUID.
3. **Безопасное хранение паролей**: локальное шифрование учетных записей SSH с помощью Microsoft.AspNetCore.DataProtection (Data Protection API) с префиксацией формата (enc:v1:).
4. **Маскирование паролей в логах**: автоматическое сокрытие точных вхождений секретных паролей в текстовом выводе и логах.
5. **Генерирует `vless://`-ссылки и QR-коды** для каждого входящего подключения (inbound), чтобы быстро настроить клиент.
6. **Мониторит работающий сервер**: статус сервиса Xray, валидация JSON-конфигурации через `xray -test -config`, статистика трафика по входящим подключениям через gRPC API Xray.
7. **Анализ и визуализация трафика**: построение гистограмм распределения трафика (Stacked Bar Chart) по входящим портам на дашборде, отображение пропорции Uplink/Downlink.
8. **Оперативное исправление при блокировках (Troubleshoot)**: функции ручной и автоматической замены/автоподбора доменов SNI (с тестом curl-задержки прямо с сервера) и мгновенный перезапуск Xray.

## Руководство по экранам

### Вкладка Deploy

1. Введите IP сервера, SSH-пользователя и пароль, либо укажите путь к приватному ключу.
2. Сохраните профиль при необходимости — конфиденциальные данные автоматически шифруются и записываются в `%localappdata%/IziProxy/profiles.json` (или `~/.config/IziProxy/profiles.json` в Linux).
3. Нажмите **Проверить соединение**, чтобы убедиться в доступности сервера до запуска деплоя.
4. Нажмите **Установить**. Вывод скрипта транслируется во вкладку Logs. По завершении выводятся сгенерированные `vless://`-ссылки и QR-коды.

### Вкладка Logs

- Содержит лог процесса установки и выполнения команд на сервере.
- Автоматически скрывает и маскирует точные совпадения SSH-паролей для предотвращения их случайной утечки.

### Вкладка Dashboard

- Показывает статус сервиса Xray в реальном времени (`systemctl is-active xray`).
- Кнопка **Перезапустить**: перезапуск службы Xray на сервере.
- Кнопка **Проверить конфиг**: выполняет `xray -test -config /usr/local/etc/xray/config.json` и выводит результат проверки.
- Секция **VPN-профили**: выводит список активных inbound-профилей (порт и SNI). Кнопка "Не работает?" раскрывает панель для замены или автоматического подбора SNI.
- Секция **Трафик**: запрашивает статистику через gRPC и строит Stacked Bar Chart распределения трафика, а также выводит прогресс-бары соотношения Uplink/Downlink по каждому входящему порту.

### Вкладка Troubleshoot

- Показывает развернутый статус состояния Xray на сервере.
- Загружает список SNI-профилей (inbound) из конфигурационного файла `/usr/local/etc/xray/config.json`.
- Позволяет осуществлять ручную замену SNI-домена для маскировки.
- Предоставляет функцию автозамены (Автоподбор): сервер тестирует список популярных TLS 1.3 доменов, определяет наименее задержанный домен (curl-замер с сервера) и применяет его с последующим рестартом Xray и генерацией новой ссылки доступа.

## Про протокол

- **VLESS + XHTTP + REALITY** — трафик маскируется под стандартную TLS-сессию HTTPS к популярным легитимным доменам (SNI), что затрудняет его обнаружение и блокировку системами DPI.
- При первоначальной установке или автоподборе скрипт проверяет доступность доменов прямо с сервера и выбирает наиболее производительный.
- Для повышения надежности создаются три inbound-подключения (на портах 443, 8443 и случайном порту) с независимыми SNI-доменами.
